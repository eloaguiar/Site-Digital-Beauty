# Digital Beauty — versão para Vercel

Esta versão preserva o conteúdo e o visual do site original e foi preparada
para publicação na Vercel com Next.js.

## Publicar

1. Envie todo o conteúdo desta pasta para um repositório no GitHub.
2. Na Vercel, clique em **Add New → Project**.
3. Importe o repositório.
4. Confirme que o framework detectado é **Next.js**.
5. Não altere os comandos ou diretórios sugeridos.
6. Clique em **Deploy**.

## Editar

- `app/page.tsx`: página inicial
- `app/gestao-de-anuncios/page.tsx`: Gestão de Anúncios
- `app/mentoria/page.tsx`: Mentoria DSN
- `app/globals.css`: aparência, cores e responsividade
- `public/brand`: imagens da marca

Para testar no computador, instale o Node.js e execute:

```bash
npm install
npm run dev
```
