DIGITAL BEAUTY — CÓPIA DO CÓDIGO-FONTE

Principais arquivos para edição:

- app/page.tsx: página inicial
- app/gestao-de-anuncios/page.tsx: página Gestão de Anúncios
- app/mentoria/page.tsx: página Mentoria DSN
- app/globals.css: cores, fontes, espaçamentos e aparência geral
- app/layout.tsx: configurações gerais e metadados
- public/brand/: logotipos e imagens da marca

Tecnologias utilizadas:

- React
- TypeScript
- Vinext/Vite
- CSS

Para executar localmente:

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute: npm install
4. Execute: npm run dev

As dependências instaladas e os arquivos temporários de compilação não estão
incluídos no ZIP. Eles são recriados automaticamente pelo comando npm install.
